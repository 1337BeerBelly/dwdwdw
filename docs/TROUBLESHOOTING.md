# Типовые проблемы и решения

Сначала почти всегда полезны три команды:

```
freeclaude-status      состояние связки
omniroute doctor       диагностика шлюза
claude doctor          диагностика Claude Code
```

---

## 1. Окно за секунду закрывается

Батник рассчитан и на двойной клик, и на запуск из терминала: при ошибке он останавливается и ждёт нажатия клавиши. Если окно всё равно исчезает — запустите его из терминала, тогда текст ошибки останется на экране:

```
cd C:\bat
freeclaude
```

---

## 2. `claude` не найден, хотя установка прошла

Проверьте, где лежит файл:

```
where claude
dir "%USERPROFILE%\.local\bin\claude.exe"
dir "%APPDATA%\npm\claude.cmd"
```

- `%USERPROFILE%\.local\bin\claude.exe` — нативная установка (winget).
- `%APPDATA%\npm\claude.cmd` — установка через npm.

PATH обновляется только в новых окнах терминала. Закройте окно, откройте заново и проверьте `claude --version`. Батники добавляют нужные папки в PATH сами, поэтому `freeclaude` находит Claude Code даже в том же окне, где он только что поставлен.

Если ничего не помогает:

```
winget install Anthropic.ClaudeCode --force
```

---

## 3. Node.js «не поддерживается» или странная ошибка про регулярные выражения

OmniRoute 3.8.51 принимает `>=22.22.2 <23` либо `>=24.0.0 <27`. Проверьте:

```
node -v
```

Если версия вне диапазона (например, 20.x, 23.x, 27.x) — поставьте LTS:

```
winget install --id OpenJS.NodeJS.LTS -e
```

При очень старом Node падение выглядит как `SyntaxError: Invalid regular expression flags` внутри чужой библиотеки — лечится тем же обновлением.

Если после установки Node не находится `npm`, закройте и откройте терминал: установщик меняет PATH для новых процессов.

Ещё одна типовая причина: в PATH раньше стоит старый бинарник из дистрибутива или из nvm. Проверьте `where node` — первая строка в выводе и есть победитель.

## 4. Дашборд не открывается, сервер не отвечает

```
omniroute status
omniroute health
netstat -ano | findstr :20128
```

- Если порт занят другим процессом, посмотрите его PID в последнем столбце вывода `netstat` и завершите: `taskkill /PID <pid> /F`.
- Если сервер нужно поднять заново: `omniroute serve --daemon --no-open`, остановить — `omniroute stop`.
- Если запускаете в отдельном окне для просмотра логов: `omniroute serve --port 20128`.
- Порт занят, а менять его нельзя? Задайте другой: `set OMNIROUTE_PORT=20200` и запускайте батники — они подхватят переменную.

Первый запуск может занимать дольше обычного (сервер собирает страницы дашборда). Батник ждёт готовности до двух минут.

---

## 5. Дашборд просит логин и пароль

Пароль задаётся в мастере первого запуска. Если он забыт:

```
omniroute reset-password
```

Если мастер не предлагает создать пароль и сразу отправляет на `/login`, запустите сервер и откройте дашборд с той же машины по адресу <http://localhost:20128> (не по IP из локальной сети). Для нелокальных подключений существует одноразовый bootstrap-токен, который печатается в лог сервера при первом запросе с внешнего адреса.

---

## 6. Claude Code отвечает ошибкой 401 от `api.anthropic.com`

Значит, Claude Code не увидел переменные окружения и пошёл напрямую в Anthropic. Причины:

- Вы запустили `claude`, а не `freeclaude` (или не через `omniroute launch`). Запускайте `freeclaude`.
- В текущем окне терминала ранее был установлен `ANTHROPIC_API_KEY` или `ANTHROPIC_BASE_URL` от другой настройки. `omniroute launch` такие переменные вычищает, но если вы задавали их глобально (например, через `setx`), лучше убрать:

```
reg delete HKCU\Environment /v ANTHROPIC_API_KEY /f
reg delete HKCU\Environment /v ANTHROPIC_BASE_URL /f
```

После этого перезайдите в Windows или откройте новое окно терминала.

- Claude Code был запущен до старта шлюза. Он читает переменные при старте — перезапустите `freeclaude`.

Проверить, куда реально уходит запрос, можно так:

```
echo %ANTHROPIC_BASE_URL%
```

в окне, где запущен Claude Code (ожидаемо — `http://localhost:20128`).

## 7. Провайдер Kiro AI не подключается

Первым делом запустите диагностику — она покажет, какие домены входа недоступны именно у вас, и предложит обходные пути:

```
kiro-check
```

Подробный разбор (портал не открывается, вход не завершается, способы без портала: Auto-Import, Import Token, API Key): [KIRO_TROUBLESHOOTING.md](KIRO_TROUBLESHOOTING.md).

Дальше — короткая версия:

- Авторизация идёт через **AWS Builder ID**: откроется страница входа, где доступны Google/GitHub или регистрация по e-mail. Подтвердите доступ и вернитесь в дашборд.
- Если окно авторизации не открылось, скопируйте ссылку из дашборда и откройте её вручную.
- В браузере должен быть выполнен вход, а всплывающие окна не заблокированы.
- Убедитесь, что вы не путаете провайдеров: нужен именно **Kiro AI**, а не «Kiro», «Kira» или иной похожий пункт, если он есть в списке.
- После подключения вернитесь в дашборд → **Providers** и нажмите тест соединения. Если тест возвращает ошибку, попробуйте переподключить аккаунт: у бесплатных тарифов бывают суточные и месячные лимиты.
- Квота закончилась? OmniRoute умеет переключаться на резервные варианты: в **Combos** задайте порядок провайдеров, а запрос направляйте на модель `auto`.

## 8. Запросы идут, но всё время ошибка или пустой ответ

```
omniroute models                 список моделей от подключённых провайдеров
omniroute test auto              тестовый запрос через умную маршрутизацию
omniroute logs                   журнал запросов
```

Если модель не найдена — проверьте, что провайдер подключён и в дашборде есть модели: <http://localhost:20128/dashboard/providers>.

Если в логах видно `429` или «rate limited» — сработал лимит провайдера; подождите либо добавьте второго провайдера и настройте fallback.

---

## 9. `winget` не найден

winget входит в состав **App Installer**:

- Windows 11 — уже установлен.
- Windows 10 — обновитесь до 22H2 и установите «Установщик приложений» из Microsoft Store, либо скачайте пакет App Installer с сайта Microsoft.

Без winget всё остальное работает: Node.js ставится установщиком с <https://nodejs.org/en/download>, Claude Code — командой `npm install -g @anthropic-ai/claude-code`.

---

## 10. Установка npm падает с ошибкой доступа (EACCES / EPERM / EEXIST)

- Закройте терминалы и редакторы, которые держат файлы пакета, и повторите.
- Антивирус или средство контроля приложений может блокировать установку глобального пакета — добавьте исключение.
- Помогает переустановка с правами администратора: откройте терминал «от имени администратора» и выполните `npm install -g omniroute`.
- Сообщения `npm warn ERESOLVE`, `deprecated`, `peer dependency` — предупреждения, установку они не прерывают. Если процесс завершился строкой `added N packages`, всё в порядке.

---

## 11. Кириллица в окне батника отображается кракозябрами

Батники переключают консоль на UTF-8 (`chcp 65001`). Если текст всё равно испорчен, запускайте их в **Windows Terminal** или смените шрифт консоли на `Consolas` / `Cascadia Mono` (клик по заголовку окна → Свойства → Шрифт).

---

## 12. Брандмауэр Windows спрашивает разрешение для Node.js

Это запрос на прослушивание порта. Если шлюз слушает только `127.0.0.1`, доступ из сети не нужен — можно нажать «Отмена», локально всё продолжит работать. Разрешайте только если сознательно открываете шлюз для других устройств (тогда включите `REQUIRE_API_KEY=true`).

---

## 13. `omniroute launch --version` показывает версию OmniRoute, а не Claude Code

Так работает разбор аргументов в OmniRoute: `--help` и `--version` перехватываются самим CLI. Версия Claude Code: `claude --version`. Версия лаунчера: `freeclaude --version` (показывает все три компонента).

---

## 14. Портал авторизации Kiro не открывается

См. отдельный документ: [KIRO_TROUBLESHOOTING.md](KIRO_TROUBLESHOOTING.md) — там пошаговые проверки (браузер, сеть, DNS, VPN, прокси, часы) и способы подключить Kiro вообще без портала.

---

## 15. Как всё удалить

```
freeclaude-stop --autostart-off     остановить шлюз и снять автозапуск
npm uninstall -g omniroute          удалить OmniRoute
npm uninstall -g @anthropic-ai/claude-code
winget uninstall Anthropic.ClaudeCode
```

Затем удалите папки `%USERPROFILE%\.omniroute` (настройки, база, ключи), `C:\bat` и запись `C:\bat` из `PATH`.
