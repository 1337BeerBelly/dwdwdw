freeclaude - Claude Code через OmniRoute
========================================

ЧТО ДЕЛАТЬ (2 шага):

1. Запустите  install.bat
   - он скопирует всё в C:\bat, добавит папку в PATH,
     поставит Node.js, OmniRoute и Claude Code,
     поднимет локальный шлюз и включит его автозапуск;
   - при установке Node.js может появиться запрос UAC - разрешите.

2. Откройте НОВОЕ окно терминала, перейдите в папку проекта и выполните:

       freeclaude

   При первом запуске откроется дашборд http://localhost:20128 -
   подключите провайдера: Providers -> Kiro AI -> Add connection -> Builder ID
   (вход через AWS Builder ID, Google или GitHub), затем запустите
   freeclaude ещё раз.


ЧАСТЫЕ КОМАНДЫ:

    freeclaude                      запустить Claude Code
    freeclaude -p "вопрос"          разовый запрос без интерактива
    freeclaude --dir C:\dev\app     запустить в папке проекта
    freeclaude --setup              только установить/проверить и поднять шлюз
    freeclaude --version            версии компонентов
    freeclaude-status               статус, список провайдеров, автозапуск
    freeclaude-stop                 остановить шлюз
    freeclaude-update               обновить OmniRoute и Claude Code

Все остальные аргументы передаются в Claude Code:
    freeclaude --continue
    freeclaude --model sonnet


ЕСЛИ НЕ ОТКРЫВАЕТСЯ ПОРТАЛ KIRO ПРИ ПОДКЛЮЧЕНИИ ПРОВАЙДЕРА:

    kiro-check              проверка доменов, шлюза, прокси и часов

    Дашборд http://localhost:20128 - локальная панель управления
    (не внешний сайт). Обычно там ничего делать не нужно: закройте
    вкладку и вернитесь в окно с Claude Code. Запретить автооткрытие:
    set FREE_CLAUDE_NO_DASHBOARD=1

    Если при входе через Google/GitHub появляется
    "Connection Failed / invalid_token_response":
      1. проверьте версию: omniroute --version (нужна 3.8.50+,
         обновление: npm install -g omniroute@latest);
      2. kiro-check --probe-kiro   покажет сырые ответы Kiro;
      3. подключите Kiro другим способом: Device Code (Builder ID),
         Auto-Import, Import Token или API Key -
         в Dashboard -> Providers -> Kiro.

    API-ключ Kiro: Dashboard -> Providers -> Kiro -> "API ключ"
    -> вставить ключ -> "Проверить и сохранить API-ключ".
    Регион AWS - как у ключа (обычно us-east-1).

    Где взять API-ключ Kiro? В аккаунте Kiro: app.kiro.dev
    -> раздел "API Keys" -> "Create key" (значение ksk_... показывают
    один раз; нужен платный тариф). Региона "Россия" у AWS нет:
    профиль Kiro живёт в us-east-1 или eu-central-1, и ключ привязан
    к региону аккаунта - проверка: kiro-check --check-kiro-key "ksk_...".
    На бесплатном тарифе ключ не нужен: подключайте по OAuth
    (Builder ID / Google / GitHub / Auto-Import / Import Token).

    Ошибка "Invalid Kiro API key or AWS region" при сохранении ключа?
    Шлюз проверяет ключ живым запросом, и это тот же отказ. Проверьте
    ключ заранее (оба региона: us-east-1 / eu-central-1):
      kiro-check --check-kiro-key "ksk_..."
    Ключи Kiro начинаются с ksk_ и привязаны к региону выдачи; если
    инструмент пишет, что ключ не принимается, - подключите Kiro
    через Builder ID / Auto-Import / Import Token.

    Ошибка 400 "Ambiguous model"? Claude Code просит модель без префикса,
    а у Kiro имена другие. Запускайте так:
      freeclaude --model kr/claude-sonnet-4.5
    (навсегда: в %USERPROFILE%\.claude\settings.json ->
     "env": { "ANTHROPIC_MODEL": "kr/claude-sonnet-4.5",
              "ANTHROPIC_SMALL_FAST_MODEL": "kr/claude-haiku-4.5" })
     Префикс kr/ нужен ОБЕИМ переменным модели.

    Ошибка 403 "The bearer ... is invalid" (и "Please run /login")?
    Это Kiro не принял подключение. Проверьте так:
      kiro-check --test-call --provider kiro --model kr/claude-sonnet-4.5
    Помогает: пересоздать API-ключ, перейти на claude-sonnet-4.5,
    либо подключить Kiro через Builder ID / Auto-Import / Import Token.

    Что писать в ANTHROPIC_AUTH_TOKEN? Это пропуск в ваш шлюз,
    а НЕ токен Kiro. Если Kiro подключён по OAuth (Учётная запись
    OAuth) - заполнять не нужно; при REQUIRE_API_KEY - ключ
    OmniRoute (sk-...). Проверка: kiro-check (строка
    ANTHROPIC_AUTH_TOKEN). Разбор - docs\TROUBLESHOOTING.md, §19.

    Ошибка 429 "Budget has been exceeded" (числа вроде 100000000)?
    Это текст стороннего шлюза (LiteLLM), а не Kiro. Проверьте:
      kiro-check                 - куда смотрит Claude Code (ANTHROPIC_BASE_URL,
                                   %USERPROFILE%\.claude\settings.json)
      kiro-check --test-call     - что отвечает ваш шлюз
      kiro-check --test-call --provider kiro   - строго через Kiro
    Работать только через Kiro: freeclaude --model kiro/auto

    Код и ссылку из окна авторизации можно открыть на телефоне:
    шлюз сам дождётся подтверждения. Без портала Kiro подключается
    через Auto-Import, Import Token или API Key - см.
    docs\KIRO_TROUBLESHOOTING.md


ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ:

    omniroute doctor        диагностика шлюза
    claude doctor           диагностика Claude Code
    freeclaude-status       состояние связки

Подробный разбор типовых ошибок - в файле docs\TROUBLESHOOTING.md,
полное руководство - в README.md.


ВТОРОЙ ИНСТРУМЕНТ В КОМПЛЕКТЕ: ОБМЕН ФАЙЛАМИ С ЧАТОМ ARENA
---------------------------------------------------------
Если нужно, чтобы ваши файлы посмотрел агент Arena:

    arena-pack C:\dev\my-app     упаковать проект (спросит задачу)
                                 - архив появится на Рабочем столе,
                                   перетащите его в чат и напишите задачу
    arena-unpack reply.zip       разложить полученные правки обратно

Бэкап затронутых файлов делается автоматически (_arena_backup), секреты
в отправляемый архив не попадают. Подробно - docs\ARENA_BRIDGE.md.

ВАЖНО ПРО БЕЗОПАСНОСТЬ: комплект настраивает шлюз так, что он доступен
только с этой машины (127.0.0.1). Не публикуйте его в сеть без ключа:
OmniRoute работает с вашими ключами и квотой провайдеров.
